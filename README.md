# Google Sheets Dashboard

A responsive analytics dashboard connected to Google Sheets.

## Features

- Live data connection
- Charts and analytics
- KPI cards
- Responsive design
- GitHub Pages ready

## Deploy to GitHub

1. Create a GitHub repository
2. Upload all files
3. Go to:

Settings → Pages

4. Select:

Deploy from branch

5. Choose:

main branch

6. Save

Your dashboard will be live.
